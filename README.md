# Phlox

여러 프로젝트가 공유하는 작업 실행 모델, 로그 시스템과 FSM 모델을 제공하는 공통 기반 라이브러리다.

## 역할과 향후 구성

- 작업 실행 모델: Track, Freight, Terminal의 역할을 바탕으로 입력과 결과의 전달 및 처리 구현의 연결을 제공한다.
- 로그 시스템: 프로젝트들이 공통으로 사용할 로그 기록 인터페이스와 처리 기능을 제공한다.
- FSM 모델: 상태, 이벤트와 전이 규칙을 표현하고 실행하는 공통 구조를 제공한다.

소비 프로젝트는 Phlox를 Git 서브모듈로 포함하고 자신의 타입과 처리 구현을 연결하여 사용한다.
프로젝트별 업무 로직과 구체적인 상태 정의는 해당 프로젝트에서 관리한다.
네트워크 공용 기능은 Cress가 담당하며 Phlox의 책임과 구분한다.

Freight는 화물의 공통 개념을 나타낸다.
구체적인 화물은 종류와 역할에 따라 Cargo 등 별도 이름을 사용할 수 있다.
Protobuf 메시지를 담당하는 화물의 명칭과 타입 관계를 포함한 세부 사항은 후속 설계에서 논의한다.

## 이름 선정 이유

- 원문 식물명: `Phlox`
- 꽃말 전체: `Unanimity.`
- 번역: 의견의 일치, 만장일치.
- 해석: 여러 프로젝트가 공통 구조와 규약을 공유한다는 역할에 연결했다.

원문 이름을 그대로 사용하며 품종이나 색상의 한정을 생략하지 않았다.
꽃말의 번역과 프로젝트 역할에 대한 해석은 구분한다.
이름 확정일은 2026-10-13이다.

출처: Kate Greenaway, [Language of Flowers (1884), 꽃 이름별 목록 P](https://www.gutenberg.org/files/31591/31591-h/31591-h.htm).

## 현재 상태

역할과 이름을 확정한 초기 저장소다.
구현과 의존성 도입은 아직 진행하지 않았으며, 구체적인 API와 내부 구성은 후속 논의에서 정한다.
